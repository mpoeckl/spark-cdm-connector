## Security

> **⚠️ IMPORTANT NOTICE**: This is a **private fork** of the original Microsoft Azure Spark CDM Connector. This repository is **NOT officially maintained by Microsoft**.

### For Microsoft Official Products

If you believe you have found a security vulnerability in the **original Microsoft Spark CDM Connector**, please report it to Microsoft through the official channels:

- **Original Repository**: https://github.com/Azure/spark-cdm-connector
- **Microsoft Security Response Center**: [https://msrc.microsoft.com/create-report](https://aka.ms/opensource/security/create-report)

### For This Private Fork

**Please do not report security vulnerabilities through public GitHub issues.**

For security issues specific to this private fork, please:

1. **Consider reporting to the [original Microsoft repository](https://github.com/Azure/spark-cdm-connector) if the issue affects the base code**
2. **Contact the fork maintainer** through private channels for security issues specific to this private fork


Please include the requested information listed below (as much as you can provide) to help us better understand the nature and scope of the possible issue:

  * Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, etc.)
  * Full paths of source file(s) related to the manifestation of the issue
  * The location of the affected source code (tag/branch/commit or direct URL)
  * Any special configuration required to reproduce the issue
  * Step-by-step instructions to reproduce the issue
  * Proof-of-concept or exploit code (if possible)
  * Impact of the issue, including how an attacker might exploit the issue


## Preferred Languages

We prefer all communications to be in English.
